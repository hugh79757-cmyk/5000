필리핀 여행을 계획 중이라면 반드시 알아야 할 이트래블(eTravel) 등록 방법을 상세히 안내합니다. 2024년 5월부터 입국신고서와 세관신고서가 하나의 QR코드로 통합되어 더욱 간편해졌습니다.

> **공식 사이트 및 참고 링크**
> 
> - [이트래블 공식 사이트](https://etravel.gov.ph/)
> - [필리핀관광부 이트래블 안내](https://philippinetourism.co.kr/travel/eTravel)
> - [이트래블 FAQ](https://etravel.gov.ph/frequently-asked-questions)

---

## 이트래블(eTravel)이란?

이트래블은 필리핀 정부가 운영하는 디지털 입국 신고 시스템입니다. 종이로 된 입국신고서, 건강상태확인서, 세관신고서를 대체하여 하나의 QR코드로 입국 절차를 간소화합니다. 필리핀 입국 시 이민국(Immigration)과 세관(Customs)에서 이 QR코드를 스캔하여 신원 및 신고 내용을 확인합니다.

---

## 등록 전 반드시 확인할 사항

이트래블 등록 전 아래 사항을 꼭 확인하세요.

첫째, 등록 시점입니다. 이트래블은 출발 시간(항공기 탑승 시간) 기준 72시간 이내에만 등록할 수 있습니다. 너무 일찍 등록하면 무효 처리되므로 출발 3일 전부터 등록을 시작하세요.

둘째, 등록 대상입니다. 나이, 성별, 국적과 관계없이 필리핀에 입국하는 모든 사람이 각자 QR코드를 발급받아야 합니다. 영유아도 예외가 아닙니다.

셋째, 외국인(한국인)은 필리핀 입국 시에만 작성하면 됩니다. 필리핀 출국(한국 귀국) 시에는 이트래블 등록이 필요 없습니다.

넷째, 이트래블은 완전 무료입니다. QR코드 발급을 위해 어떠한 결제도 요구하지 않습니다. 결제를 요구하는 사이트는 사기이니 주의하세요.

다섯째, 별도 앱 설치가 필요 없습니다. 이트래블은 모바일 웹 기반 시스템으로 스마트폰이나 PC 브라우저에서 바로 접속 가능합니다.

## STEP 1: 이트래블 계정 만들기

이트래블을 처음 이용한다면 계정을 먼저 생성해야 합니다.

**접속 주소**: [etravel.gov.ph/authentication](https://etravel.gov.ph/authentication)

### 1-1. 이메일 입력 및 OTP 인증

"Create an account"를 선택한 후 아이디로 사용할 이메일 주소를 입력합니다. 입력한 이메일로 6자리 OTP(일회용 비밀번호)가 발송됩니다. 이메일을 확인하여 OTP를 입력하세요. 스팸함도 확인해 보시기 바랍니다.

### 1-2. 비밀번호 설정

8자 이상의 비밀번호를 설정합니다. 영문 대문자, 소문자, 숫자, 특수문자를 조합하면 보안이 강화됩니다.

### 1-3. 개인정보 입력 (Personal Information)

여권에 기재된 대로 정확하게 입력해야 합니다.

| 항목                   | 입력 내용                    |
| -------------------- | ------------------------ |
| First Name           | 이름 (여권 영문 표기 그대로)        |
| Middle Name          | 중간 이름 (없으면 비워두기)         |
| Last Name            | 성 (여권 영문 표기 그대로)         |
| Suffix               | 호칭 (없으면 비워두기)            |
| Date of Birth        | 생년월일                     |
| Sex                  | 성별 (Male/Female)         |
| Civil Status         | 결혼 여부 (Single/Married 등) |
| Nationality          | 국적 (South Korea)         |
| Passport Number      | 여권번호                     |
| Passport Expiry Date | 여권 만료일                   |

### 1-4. 거주지 주소 입력 (Permanent Country of Residence)

한국 거주자라면 South Korea를 선택하고 영문 주소를 입력합니다. 네이버에서 "영문주소 변환"을 검색하면 한글 주소를 영문으로 변환할 수 있습니다.

### 1-5. 등록 내용 확인 (Onboarding Summary)

입력한 내용을 최종 확인한 후 제출합니다. 계정이 생성되면 대시보드(Dashboard)로 이동합니다.

## STEP 2: 입국신고서 작성 (New Travel Declaration)

계정 생성 후 실제 입국 정보를 등록합니다.

**접속 주소**: [etravel.gov.ph/new-travel-declaration](https://etravel.gov.ph/new-travel-declaration)

### 2-1. 등록 대상자 및 입국 유형 선택 (Travel Registration)

| 항목     | 선택 내용                         |
| ------ | ----------------------------- |
| 등록 대상자 | FOR ME (본인) / FOR OTHER (가족)  |
| 이동 수단  | AIR (항공) / SEA (선박)           |
| 입출국 유형 | ARRIVAL (입국) / DEPARTURE (출국) |

일반 여행자라면 FOR ME → AIR → ARRIVAL을 선택합니다.

### 2-2. 여행 상세 정보 입력 (Travel Details)

**여행 목적 (Purpose Of Travel)** 선택 항목은 다음과 같습니다. Holiday/Pleasure/Vacation은 휴가 및 여행으로 일반 관광객이 선택하며, Business/Professional은 비즈니스 목적, Visit Friends/Relatives는 친지 방문, Transit은 환승 및 경유 시 선택합니다.

**여행자 유형 (Traveller Type)**은 일반 승객이라면 AIRCRAFT PASSENGER를, 승무원이라면 FLIGHT CREW를 선택합니다.

### 2-3. 항공편 정보 입력 (Flight Information)

| 항목                     | 입력 내용                         |
| ---------------------- | ----------------------------- |
| Name Of Airline        | 이용 항공사 선택                     |
| Flight Number          | 항공편명 (예: KE631, 7C2601 등)     |
| Country of Origin      | South Korea                   |
| Airport of Origin      | INCHEON (인천) 또는 GIMHAE (김해) 등 |
| Date of Departure      | 한국 출발일                        |
| Date of Return         | 한국 귀국일 (미정이면 대략적 날짜 입력)       |
| Airport of Destination | 도착 공항 (항공편 입력 시 자동 선택)        |
| Date of Arrival        | 필리핀 도착일                       |

**주요 항공사명 영문 표기**는 다음과 같습니다. 대한항공은 Korean Air, 아시아나항공은 Asiana, 제주항공은 Jeju Air, 진에어는 Jin Air, 티웨이항공은 Tway Airlines, 에어부산은 Air Busan, 에어서울은 Air Seoul, 세부퍼시픽은 Cebu Pacific, 필리핀항공은 Philippine Airlines입니다.

### 2-4. 필리핀 내 체류 주소 입력 (Destination upon arrival)

숙소 유형에 따라 선택합니다. Hotel/Resort는 호텔이나 리조트 숙박 시 호텔명을 검색하여 선택하고, Residence는 에어비앤비나 지인 집 등 거주지 형태일 경우 주소를 직접 입력합니다. Transit Via Airport는 환승이나 경유만 하는 경우 선택합니다.

호텔명이 검색되지 않으면 Residence를 선택하고 호텔 주소를 직접 입력하면 됩니다. 여러 숙소를 이용할 경우 첫 번째 숙소 정보만 입력해도 무방합니다.

### 2-5. 건강 상태 신고 (Health Declaration)

| 질문                    | 답변            |
| --------------------- | ------------- |
| 지난 30일간 방문 국가         | 선택 입력 (필수 아님) |
| 지난 30일간 전염성 질환자 접촉 여부 | YES / NO      |
| 지난 30일간 아팠던 적 있는지     | YES / NO      |

건강에 이상이 없었다면 모두 NO를 선택합니다.

## STEP 3: 세관신고서 작성 (Customs Declaration)

입국신고서 작성이 끝나면 자동으로 세관신고 페이지로 이동합니다.

### 3-1. 세관신고 사항 없는 경우

대부분의 일반 여행자는 신고 사항이 없습니다. "세관신고사항 없음"을 선택하고 다음 항목을 입력합니다.

| 항목        | 입력 내용                |
| --------- | -------------------- |
| 동반 가족 수   | 함께 입국하는 가족 인원        |
| 필리핀 방문 경험 | 첫 방문 여부              |
| 수하물 개수    | 위탁 수하물 + 기내 수하물 총 개수 |

### 3-2. 세관신고 사항 있는 경우

다음 물품을 반입할 경우 신고가 필요합니다. 외화 1만 달러(USD) 이상 또는 5만 페소 이상 현금, 담배 2보루(400개비) 초과, 주류 2병(각 1리터) 초과, 반입 규제나 제한 또는 금지 물품이 해당됩니다.

해당되는 경우 "세관신고사항 있음"을 선택하고 상세 내역을 작성합니다.

### 3-3. 전자서명 (Declaration Signature)

화면에 손가락이나 마우스로 서명합니다. 여권 서명과 동일하지 않아도 됩니다.

### 3-4. 최종 확인 및 QR코드 발급

입력 내용을 확인한 후 제출하면 즉시 QR코드가 발급됩니다.

## QR코드 저장 및 활용 방법

QR코드 발급 후 반드시 아래 방법으로 저장하세요.

첫째, 스크린샷을 찍어 휴대폰 갤러리에 저장합니다. 둘째, QR코드 이미지를 다운로드합니다. 셋째, 종이에 인쇄해서 보관하면 더욱 안전합니다.

**QR코드 분실 시 복구 방법**: [etravel.gov.ph/search](https://etravel.gov.ph/search)에서 참조번호(Reference Number)와 생년월일을 입력하면 QR코드를 다시 확인할 수 있습니다.

---

## QR코드 색상의 의미

발급받은 QR코드 색상에 따라 입국 절차가 달라집니다.

**녹색(Green) QR코드**는 정상적으로 등록이 완료된 경우입니다. 입국 심사대에서 이민국 검사만 받으면 됩니다.

**적색(Red) QR코드**는 정보가 불완전하거나 지난 30일간 건강 이상이 있었던 경우 발급됩니다. 입국 시 검역소(BOQ) 추가 검사 후 이민국 심사를 받습니다.

---

## 가족 대리 등록 방법

만 18세 미만 자녀나 직계 가족은 본인 계정에서 대리 등록이 가능합니다.

대시보드에서 "New Travel Declaration"을 선택한 후 "FOR OTHER (Family Member)"를 선택합니다. 가족 정보를 입력하고 동일한 절차로 진행하면 됩니다. 단, 전자 세관신고 특성상 가족이 아닌 타인의 대리 등록은 불가합니다.

## 자주 묻는 질문 (FAQ)

**Q. 이트래블 등록은 언제 해야 하나요?**

출발 72시간(3일) 이내에 등록해야 합니다. 너무 일찍 등록하면 사용할 수 없습니다.

**Q. 핸드폰 본인 인증이 필요한가요?**

아니요. 이메일 인증만 받으면 됩니다. 본인 명의 핸드폰이 없어도 등록 가능합니다.

**Q. 앱을 설치해야 하나요?**

아니요. 이트래블은 웹 기반 시스템으로 브라우저에서 바로 접속하면 됩니다. eGovPH 앱을 통해서도 가능하지만 필수는 아닙니다.

**Q. 숙소를 여러 군데 이용하는데 어떻게 입력하나요?**

첫 번째 숙소 정보만 입력하면 됩니다.

**Q. 호텔명이 검색되지 않아요.**

Residence를 선택하고 호텔 주소를 직접 입력하세요.

**Q. 항공편이 검색되지 않아요.**

이전 화면에서 "Special Flight"를 선택한 후 항공편명을 직접 입력하세요.

**Q. 등록 후 정보 수정이 가능한가요?**

입국 심사 전까지는 "Edit Registration" 메뉴에서 일부 정보 수정이 가능합니다. 단, 수정된 정보는 새로 등록한 QR코드에만 반영됩니다.

**Q. QR코드를 여러 개 발급받았는데 어떤 걸 사용해야 하나요?**

하나만 선택해서 제시하세요. 여러 QR코드를 제시하면 혼란이 생길 수 있습니다.

## 입국 당일 체크리스트

필리핀 도착 전 아래 사항을 최종 점검하세요. 이트래블 QR코드 스크린샷 또는 인쇄본 준비, 여권 유효기간 6개월 이상 확인, 귀국 항공권 또는 제3국 출국 항공권 준비, 체류 기간 중 숙소 예약 확인서가 필요합니다.

입국 심사 시 QR코드와 여권을 함께 제시하면 빠르게 통과할 수 있습니다.

---

## 마무리

이트래블은 한 번만 익숙해지면 5~10분 내로 등록을 마칠 수 있습니다. 출발 전 여유 있게 등록하고 QR코드를 반드시 저장해 두세요. 즐거운 필리핀 여행 되시기 바랍니다!
