## 2. Q3-치료 규칙 (v5)

### 2.1 목적
건강기능식품/화장품 콘텐츠에서 "치료/완치/개선(질환)" 등 의약품으로 오인될 수 있는 표현을 탐지한다. "도움을 줍니다/도움을 줄 수 있습니다" 등 hedged 표현은 제외한다.

### 2.2 탐지 대상 패턴

| 패턴 | 정규식 | 설명 |
|------|--------|------|
| 증상 완화 | `증상\s*완화` | "갱년기 증상 완화에 도움을 줍니다" |
| 탈모 개선 | `탈모\s*개선` | "탈모 개선을 목적으로" |
| 피로 완화 | `피로\s*완화` | "피로 완화에 도움을 줍니다" |
| 개선(질환) | `(여드름|탈모|불면|염증|통증|수면|간)\s*개선` | 질환명 + 개선 결합 |
| 완화(질환) | `(여드름|탈모|불면|염증|통증|피로|수면)\s*완화` | 질환명 + 완화 결합 |
| 피부 탄력 개선 | `피부의\s*탄력이\s*눈에 띄게 개선` | 화장품 단정형 |

### 2.3 오탐 회피 로직 (±50자 컨텍스트)

| # | 제외 대상 | 패턴 | 예시 |
|---|----------|------|------|
| 1 | 부정문 | `치료\s*목적[으로]*\s*(사용\|복용)\s*(하지\s*마\|말아야\|해서는\s*안)` | "질병 치료 목적으로 사용해서는 안 됩니다" |
| 2 | 법정 표기 | `의약품이\s*아닙니다`, `의약품\s*아닌` | "건강기능식품은 의약품이 아닙니다" |
| 3 | hedged-도움 | `도움이\s*될\s*수\s*있` | "피로 완화에 도움이 될 수 있습니다" |
| 4 | hedged-도움(변형) | `도움을\s*줄\s*수\s*있` | "염증 완화에 도움을 줄 수 있습니다" |

### 2.4 핵심 규칙
- **hedged "도움을 줄 수 있습니다"가 ±50자 내에 있으면 → 제외** (정상 성분 설명)
- hedged 없이 "피로 완화에 도움을 줍니다" 또는 "탈모 개선을 목적으로" → **위반**

## 3. Q5-상품관련성 규칙 (v5)

### 3.1 목적
글의 주제(슬러그)와 무관한 상품이 본문에 혼입된 경우 탐지한다. 예: 사람 건강 글에 반려동물 상품.

### 3.2 탐지 알고리즘

```
1. 슬러그에 반려동물 키워드(강아지/고양이/반려견/묘견/어항/케이지) 포함 여부 확인
   → 포함하면 정상 (반려동물 전용 글)
2. 본문에서 반려동물 키워드 탐지
   → 없으면 정상
3. 본문 H2/H3에서 반려동물 상품 확인:
   ###?\s*\d*위[:\s]*(?:[^\n]*)(?:강아지|고양이|반려견|묘견)
   → 탐지되면 Q5 위반
```

### 3.3 오탐 회피
- 슬러그에 "강아지/고양이/반려" 포함 → 정상 (반려동물 전용 글)
- 본문 내 반려동물 키워드가 H2/H3 상품명에 없으면 정상 (일반 언급)

## 4. Q6-미검증 인증 규칙 (v5)

### 4.1 목적
"식약처 인증을 받았습니다", "특허원료" 등 근거가 불확실한 인증/특허 표현을 탐지한다.

### 4.2 탐지 대상 패턴

| 패턴 | 정규식 |
|------|--------|
| 식약처 인증 단정 | `식약처\s*인증\s*(을\s*받았\|했\|입니다\|인지\|의\s*여부)` |
| 인증 획득 단정 | `인증[을을이가 ]{0,2}(받았\|획득\|취득\|했습니다\|했는지)` |
| 특허 단정 | `특허[를을이가 ]{0,2}(받았\|획득\|취득\|보유\|했습니다)` |

### 4.3 오탐 회피 (±60자 컨텍스트)

| # | 제외 대상 | 패턴 |
|---|----------|------|
| 1 | 질문형 | `인증.*[받았]+나요\?`, `인증.*받았[어]+요\?` |
| 2 | 일반 조언 | `기능성\s*원료\s*(를을\|을)\s*(확인\|체크\|고려\|찾)` |
| 3 | 부정문 | `(인증\|승인\|허가)\s*(받지\|못\|안\|아닌)` |
| 4 | 법정 인증 | `식약처[가에서]*\s*(인정\|등록\|고시)\s*(한\|된)\s*기능성` |
