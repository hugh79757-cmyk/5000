# Phase 25: CUAP 거미줄 엔티티 시스템 — SPEC

**Objective:** CUAP 10개 블로그 간 크로스 링크 시스템을 구축하여 사용자 순회를 유도하고 광고 노출 기회를 2~3x 증가시킨다.

**Mode:** implementation

---

## Requirements

### R1: CUAP 엔티티 링크 DB 구축
- **Current:** CUAP 블로그 간 연결 정보 없음
- **Target:** `cuap_entities` 테이블 + `cuap_link_graph` 인접 행렬 구축
- **Acceptance:**
  - [ ] `cuap_entities` 테이블 생성 (entity_type, entity_name, blog_id, post_slug, post_url, link_label, category, priority, published)
  - [ ] `cuap_link_graph` 테이블 생성 (source_blog, target_blog, link_type, weight)
  - [ ] 10개 블로그 간 연결 그래프 초기 데이터 삽입

### R2: 엔티티 등록 시스템
- **Current:** 발행 시 엔티티 등록 없음
- **Target:** 발행 완료 시 `cuap_entities`에 자동 등록
- **Acceptance:**
  - [ ] `register_cuap_entity()` 함수 구현
  - [ ] `pipeline.py` 발행 흐름에 등록 호출 삽입
  - [ ] 등록 후 `published=1` 마킹

### R3: 인라인 크로스 링크 삽입
- **Current:** 본문에 타 블로그 링크 없음
- **Target:** 본문 마크다운에서 관련 키워드 발견 시 타 블로그 링크 자동 삽입
- **Acceptance:**
  - [ ] `inject_cross_blog_links()` 함수 구현
  - [ ] 글당 최대 3개 인라인 링크 삽입
  - [ ] H1/H2 헤딩 내부에는 링크 미삽입
  - [ ] 이미 []() 링크 안에 있는 텍스트는 건너뜀

### R4: 크로스셀 카드 생성
- **Current:** `related.html`은 같은 블로그 내 Related만 표시
- **Target:** 본문 하단에 타 블로그 3개 + 같은 블로그 1개 크로스셀 카드 표시
- **Acceptance:**
  - [ ] `build_cross_sell_card()` 함수 구현
  - [ ] 블로그별 아이콘 + 제목 + 링크 카드 HTML 생성
  - [ ] 모바일/데스크톱 반응형 레이아웃

### R5: 퍼널 헤더 생성
- **Current:** 퍼널 진입점 없음
- **Target:** 본문 상단에 "다른 추천도 확인해보세요" 퍼널 네비게이션 표시
- **Acceptance:**
  - [ ] `build_funnel_header()` 함수 구현
  - [ ] 관련 카테고리 3개 링크 표시
  - [ ] 블로그별 테마 색상 적용

### R6: Hugo 레이아웃 통합
- **Current:** `related.html`은 같은 블로그 내 Related만 표시
- **Target:** `cuap-spider-links.html` partial로 교체하여 크로스 블로그 링크 표시
- **Acceptance:**
  - [ ] `cuap-spider-links.html` partial 생성
  - [ ] `single.html`에서 `related.html` 대체
  - [ ] 10개 블로그 전부 적용

### R7: 10개 블로그 연결 그래프 정의
- **Current:** 블로그 간 연결 관계 미정의
- **Target:** `CROSS_GRAPH` 딕셔너리로 주요/보조 연결 관계 정의
- **Acceptance:**
  - [ ] 10개 블로그별 primary/secondary/use_cases 정의
  - [ ] 자연스러운 퍼널 경로 설계 (뷰티→가전→캠핑 등)
  - [ ] 연결 강도(weight) 초기값 설정

## Boundaries

### In Scope
- `shared/cuap_entity_linker.py` 신규 생성
- `pipelines/curation/pipeline.py` 발행 흐름 수정
- `layouts/partials/cuap-spider-links.html` 신규 생성
- `layouts/_default/single.html` 수정 (related.html 대체)
- `data/cuap_links.db` SQLite DB 생성

### Out of Scope
- ETAP 기존 `entity_linker.py` 수정
- STAP/TAP 외부 프로젝트 연동
- 실시간 사용자 트래킹/분석
- A/B 테스트 프레임워크
- 광고 수익 직접 최적화 (AdSense 설정 변경)
- 기존 발행된 글 수정 (다음 발행분부터 적용)

## Acceptance Criteria

###Functional
- [ ] CUAP 10개 블로그 간 크로스 링크 시스템 구축
- [ ] 본문 발행 시 자동으로 타 블로그 링크 삽입
- [ ] 크로스셀 카드가 본문 하단에 표시
- [ ] 퍼널 헤더가 본문 상단에 표시
- [ ] 세션당 평균 페이지뷰 1.2 → 2.5+ 증가
- [ ] 광고 노출 기회 2~3x 증가

### Non-Functional
- [ ] 링크 삽입 처리 시간 < 100ms
- [ ] DB 쿼리 시간 < 50ms
- [ ] Hugo 빌드 시간 증가 < 5초
- [ ] 모바일/데스크톱 반응형 지원
