  <action>
    Create `scripts/fix_baked_crosslink_cards.py` that scans all 10 CUAP blog content/posts/*/index.md files and fixes wrong cross-link hrefs.

    Algorithm:
    1. For each CUAP blog:
       a. Glob `/Users/twinssn/Projects/cuap/{blog_id}/content/posts/*/index.md`
       b. For each file, read content
       c. If "이런 상품도 좋아하실 거예요" NOT in content → skip
       d. Find the cross-link card section (between `🛍️ 이런 상품도 좋아하실 거예요` and closing `</div>`)
       e. Extract all hrefs from `<a href="...">` tags within the card
       f. For each href URL:
          - Parse domain/subdomain to determine target blog_id
          - Query cuap_entities for the correct `post_url` using the link_label text as `entity_name`
            `SELECT post_url FROM cuap_entities WHERE blog_id=? AND link_label=? AND published=1 ORDER BY priority DESC, rowid DESC LIMIT 1`
          - If DB returns a correct URL and it differs from the href → replace
          - If DB returns no match → log warning, leave href unchanged (avoid breaking links)
       g. Write modified content back to file (WITHOUT .bak backup — see note below)

    Key details:
    - Dry-run mode: `--dry-run` prints what would change without modifying files
    - Backup strategy: DO NOT create .bak files — these are in Hugo content directories and .bak files would break Hugo builds. Instead:
      - Copy to `/tmp/fix_baked_crosslink_cards_before/{blog_id}/{slug}/index.md` before modification
      - On completion, remove the /tmp backup directory
    - Report: print blog_id, file count, hrefs checked, hrefs fixed, hrefs no-match
    - Error handling: wrap each file in try/except, log errors, continue to next file
    - Use parameterized queries to prevent SQL injection
    - The card HTML format is:
      ```html
      <div style="margin:20px 0;padding:16px;background:#fafbfc;border-radius:12px;border:1px solid #e8ecf0">
      <p style="margin:0 0 10px;font-weight:600;font-size:15px;color:#374151">🛍️ 이런 상품도 좋아하실 거예요</p>
      <div style="display:flex;flex-wrap:wrap;gap:4px">
      <a href="..." style="...">🔌 ...</a>
      <a href="..." style="...">👶 ...</a>
      ...
      </div>
      </div>
      ```

    IMPORTANT:
    - Task 1 (fix DB) must be run BEFORE this script, because this script queries cuap_entities for correct URLs
    - The regex for extracting hrefs from card: `href="(https://[^"]+)"` within the card section
    - Skip files where the current href already matches the correct URL from DB
    - Handle both http:// and https:// URLs in the href
