<objective>
**Root Cause Fix: Make `_write_hugo_post()` return a `"url"` key so entity registration uses the correct slug.**

**Purpose:** The cross-link system registers entities using `result.get("url")` at pipeline.py:1064, but `hugo_writer._write_hugo_post()` never returns a `"url"` key (only `"success"` and `"file"`). This causes the fallback to `_make_slug(keyword)` which produces `20260726-{keyword}` format slugs that don't exist on disk → all 4 cross-link URLs 404.

The publisher.py:530 local `_write_hugo_post()` DOES return `"url"`, but it's overridden at publisher.py:762-770 by `hugo_writer._write_hugo_post()` which doesn't. The fix is additive — add `"url"` to the return dict, preserving the existing `"file"` key.

A defensive fallback is also added in pipeline.py: if `result["url"]` is missing (e.g., for non-CUAP callers), extract slug from `result["file"]` path which always contains the correct on-disk slug.

**Output:** Fixed code in `hugo_writer.py` (+2 lines), `pipeline.py` (+8 lines), `cuap_entity_linker.py` (+3 lines). Commit: `fix(crosslink): add url return from _write_hugo_post() and file-based slug fallback`
</objective>
