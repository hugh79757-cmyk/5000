# Worklog: WL-20260921-X0-template-regression-rule

**Date**: 2026-09-21
**Scope**: 템플릿 회귀 규칙 문서화 — X-0 규칙 제정
**Trigger**: 기존 VERDICT의 아이템 상태를 이전 보고서 템플릿에서 복사하여 현재 라이브 상태와 불일치한 사례 재발

---

## 정의

**템플릿 회귀**: 이전 보고서/VERDICT의 항목 상태를 현재 상태 검증 없이 그대로 복사하는 패턴. 원본 인용(citation)이 아닌 템플릿을 기준으로 삼으면 오래된/잘못된 상태가 전파됨.

## X-0 규칙 (제6차 템플릿 회귀 규칙)

> 상태 보고서 작성 시, 각 항목의 상태를 이전 템플릿에서 복사하지 않는다.
> 반드시 원본 VERDICT의 citation으로부터 현재 라이브 상태를 직접 확인하여 기록한다.

- 상태의 출처는 "이전 보고서"가 아니라 "원본 VERDICT"이다
- 원본 VERDICT이 존재하지 않으면 [검증불가]로 분류하고 복구 계획을 명시한다
- 템플릿에서 물려받은 상태는 검증 전까지 임시로만 취급한다

| **6** | **X-0 규칙** | **VERDICT citation 없이 상태 전파, 라이브 미확인** |

## 교훈

- 보고서는 "무엇이 완료되었는지"가 아니라 "현재 어떤 상태인지"를 기록한다
- 이전 템플릿은 구조만 재사용한다. 상태 값은 매번 재확인이 필요하다
- 템플릿 회귀는 라이브 시스템과 괴리된 보고서 → 잘못된 의사결정으로 직결

## 적용 범위
