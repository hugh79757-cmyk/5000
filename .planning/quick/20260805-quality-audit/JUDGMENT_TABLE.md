## unpause 실행 커맨드 (통과·조건부 해제 블로그만)

```bash
# CAP: 조건부 4개(compare, hotissue, rank, deal/ev/guide/tco/pick은 통과) → 전체 8개 대상
# TAP: 조건부 4개(travel, travel1, travel3, travel4) + 통과 1개(travel2) → 전체 5개 대상

# 실행 전: C1~C3, T1~T3 구현 완료 확인 필요

# CAP 블로그 unpause
sed -i 's/status: paused/status: active/' config/blogs.d/cap.yaml

# TAP 블로그 unpause  
sed -i 's/status: paused/status: active/' config/blogs.d/tap.yaml

# 검증
grep -A1 '^  - id:' config/blogs.d/cap.yaml config/blogs.d/tap.yaml | grep -E 'id:|status:'
```
