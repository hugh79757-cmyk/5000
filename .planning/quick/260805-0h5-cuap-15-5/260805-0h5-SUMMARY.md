## Deviations

### Auto-fixed Issues (Rule 3)

1. **bike-hugo 1차 배포 시 DNS 레코드 미생성** — custom domain trigger는 생성되었으나
   auth NS에 A 레코드가 없었다(`dig @sonia.ns.cloudflare.com bike.informationhot.kr A +short`
   → 빈 결과). wrangler deploy 재실행으로 DNS 레코드 생성 확인(`172.67.148.97 104.21.95.203`).
   커밋 내용 변화 없음(코드 변경 없음, 배포 재시도만).
2. **golf/homeappliance 배포 직후 일시적 HTTP 500** — 배포 직후 첫 요청에서 500 관찰,
   재시도(3~5회) 및 잠시 후 재검증 시 200으로 정상화. Phase 28 canonical worker의
   asset 전파 일시 지연으로 판단, 지속 500은 아님(반복 검증 5/5 200 + 404 경로 404 확인).

### 로컬 DNS 캐시 (환경 특성, 수정 불필요)

로컬 라우터(192.168.1.1)가 신규 도메인 2개(massage/car)의 이전 NXDOMAIN을 음성 캐싱.
DNS 레코드 자체는 auth NS + 1.1.1.1 + 8.8.8.8에서 [검증됨]. 캐시 TTL 만료 후 자동 해소.
