    Add a new helper function `fix_markdown_cta_links()` and call it after the AI output is received (before `body_md` is used further). Place it near the existing CTA fallback logic (around line 980).

    ```python
    def fix_markdown_cta_links(body_md: str) -> str:
        """AI가 생성한 markdown CTA 링크를 HTML 버튼으로 변환.
        
        패턴: [텍스트](https://link.coupang.com/...)
        → <div style="text-align:center"><a class="btn-price-check" href="URL">🛒 텍스트</a></div>
        
        wrapper div로 감싸서 버튼 중앙 정렬 보장 (btn-price-check가 display:table이어도
        주변 텍스트와의 레이아웃 안정성 확보).
        """
        import re
        # Coupang affiliate 링크만 대상 (다른 일반 링크는 건드리지 않음)
        CTA_PATTERN = r'\[([^\]]+)\]\((https?://(?:link\.coupang\.com|www\.coupang\.com)[^)]+)\)'
        replacement = r'<div style="text-align:center;margin:1.5rem 0"><a class="btn-price-check" href="\2">🛒 \1</a></div>'
    ```
