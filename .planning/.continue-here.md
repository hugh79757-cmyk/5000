## Bugs & Issues Discovered

### 1. kitchen-hugo fade-in-section 본문 공백
- **증상**: 모바일에서 헤더 정상 렌더링, 본문만 공백 (흰색)
- **원인**: `custom.css` `.fade-in-section { opacity: 0 }`가 본문 요소를 투명하게 만들었으나, IntersectionObserver가 `.is-visible` 클래스를 추가하지 못해 `opacity: 0` 상태 유지
- **해결책**: fade-in-section CSS 블록 + IntersectionObserver JS 코드 제거
- **미해결 여부**: ✓ 해결 완료

### 2. 에이전트 한글 인코딩 손상 (5회 재발)
- **증상**: 보고서에 중국어 문자 혼입. 한글 URL/텍스트를 타이핑으로 전달 시 글자 훼손
- **원인**: 에이전트/도구 체인에서 한글 텍스트 처리 시 인코딩 손상 발생
- **해결책**: 한글 텍스트를 타이핑으로 보고서에 포함하는 방식 중단, 스크린샷 기반으로 전환
- **미해결 여부**: 프로세스 고정으로 대응
