### Template 분석 — 핵심 발견

#### `layouts/index.html` (첫페이지 ✅)
```html
{{ $image := .Resources.GetMatch "thumbnail.*" }}
{{ if $image }}
    <img src="{{ $image.RelPermalink }}" ...>
```
→ `$image.RelPermalink` = Hugo가 처리한 올바른 경로 반환 → **정상 작동**

#### `layouts/_default/single.html` (본문 ❌)
```html
{{- if .Params.cover.image }}
{{- $cover := .Params.cover }}
<img loading="lazy" src="{{ $cover.image }}" ...>
```
→ `$cover.image` = `"thumbnail.webp"` raw값 그대로 출력 → **상대경로 브라우저 의존**

### 실제 배포 상태 검증

### 발견된 문제점 3가지

#### 1. `single.html`의 커버 이미지 경로 처리 취약

`single.html`이 Hugo의 `cover.html` partial을 **사용하지 않고** 자체 inline 코드로 처리함. PaperMod 원본 `cover.html`은 page bundle resource를 정식으로 조회(`.Resources.GetMatch`)하지만, custom single.html은 raw frontmatter 값만 출력.

- **Page bundle article**: `src=thumbnail.webp` (상대경로) — Hugo가 `public/posts/slug/thumbnail.webp`에 복사하므로 정상 동작
- **Flat .md file**: 커버 없음 (skip)
- **절대 URL (R2/legacy-img)**: 있을 경우 raw URL로 출력되어야 하는데 현 정보탭에는 해당 사례 없음

#### 2. `og:image` 메타태그 잘못된 경로

생성된 HTML에서:
```html
<meta property="og:image" content="https://informationhot.kr/thumbnail.webp">
```
→ `absURL("thumbnail.webp")`가 사이트 ROOT로 잘못 해석됨  
→ SNS 공유 시 썸네일 안 나올 가능성 高  
→ **원인**: frontmatter에 `cover.relative: true` 누락  
→ PaperMod의 `opengraph.html`이 `cover.relative` 체크 후 `absURL` vs `path.Join .RelPermalink` 분기

#### 3. `_redirects` 간섭 가능성

```yaml
/posts/2025-07-* /posts/ 301
```
→ `*` glob이 슬래시까지 포함하므로 `/posts/2025-07-*/thumbnail.webp` 요청도 `/posts/`로 리디렉트됨  
→ 영향 범위: 37개 flat .md 파일 중 date가 `2025-07-`로 시작하는 구형 글들

### 현장 재현 불가

실제 curl로 확인한 바, page bundle article들의 `thumbnail.webp`는 정상 200 응답.  
→ **유저의 정확한 재현 스텝 필요** (특정 URL, 브라우저/디바이스, 캐시 상태 등)

## 재발방지 플랜

### 🔴 즉시 수정 — 1번 (3분)
**`single.html` 커버 이미지 경로 → PaperMod `cover.html` partial 사용**

```html
<!-- 현재 (취약) -->
<figure class="entry-cover">
    <img loading="lazy" src="{{ $cover.image }}" ...>
</figure>

<!-- 수정안: Hugo page bundle resource 우선 조회 -->
{{- if .Params.cover.image }}
  {{- $pageBundleCover := (.Resources.ByType "image").GetMatch (printf "*%s*" .Params.cover.image) }}
  {{- $globalResourcesCover := (resources.ByType "image").GetMatch (printf "*%s*" .Params.cover.image) }}
  {{- $cover := (or $pageBundleCover $globalResourcesCover) }}
  {{- $imgSrc := $cover.Permalink | default (.Params.cover.image | absURL) }}
  <figure class="entry-cover">
    <img loading="lazy" src="{{ $imgSrc }}" ...>
  </figure>
{{- end }}
```

또는 아예 PaperMod의 `cover.html` partial을 재사용:
```go
{{- partial "cover.html" (dict "cxt" . "IsSingle" true "isHidden" false) }}
```
