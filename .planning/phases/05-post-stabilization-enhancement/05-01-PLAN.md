### 1.2 index.md 수정

각 글의 `content/posts/{slug}/index.md`에서 다음 3가지를 수정:

**a) 썸네일 키 변경:** `cover.image:` → `featureimage:`
```diff
- cover:
-   image: "https://..."
+ featureimage: "https://..."
```

**b) CTA HTML 추가** (본문 마지막, coupang 섹션 직후):
```html
<div class="cta-box">
  <p style="margin:0;font-size:1.1rem;">여행 숙소를 찾고 계신가요?</p>
  <a href="https://kr.trip.com/?Allianceid=7451816&SID=283255449&trip_sub1=&trip_sub3=D14664967" target="_blank" rel="nofollow">트립닷컴에서 최저가 확인하기</a>
</div>
```

**c) `{{}}` 라인 제거** (빈 템플릿 라인 삭제)

**d) "지도에서 보기" 평문 제거** (패턴에 매칭되지 않은 평문 삭제)
