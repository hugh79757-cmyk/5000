### 3.1 발행 글 HTML 검증 함수

**파일:** `shared/publishers/content_enhancer.py` 또는 신규 `shared/post_validator.py`

발행 완료 후 Hugo build된 HTML을 파싱하여 다음 항목 검증:

```python
def validate_post_html(html: str, blog_id: str) -> dict:
    issues = []
    # 1. CTA 존재 여부
    if "cta-box" not in html and blog_id in TAP_TRAVEL_BLOGS:
        issues.append({"severity": "ERROR", "check": "cta_html", "msg": "Trip.com CTA 누락"})
    # 2. {{}} 잔재
    if "{{" in html:
        count = html.count("{{")
        issues.append({"severity": "WARNING", "check": "empty_template", "msg": f"{{{{}}}} 잔재 {count}개"})
    # 3. 썸네일 존재 (og:image 메타 태그)
    if 'property="og:image"' not in html and 'name="twitter:image"' not in html:
        issues.append({"severity": "WARNING", "check": "thumbnail", "msg": "og:image 메타 태그 없음"})
    # 4. 지도보기 평문
    if "지도에서 보기" in html:
        issues.append({"severity": "WARNING", "check": "map_text", "msg": "지도보기 평문 잔재"})
    # 5. 최소 글자수
    body_text = re.sub(r"<[^>]+>", "", html)
    if len(body_text) < 500:
        issues.append({"severity": "ERROR", "check": "min_length", "msg": f"본문 {len(body_text)}자 (최소 500)"})
    return {"passed": len([i for i in issues if i["severity"] == "ERROR"]) == 0, "issues": issues}
```

**호출 위치:** `shared/publisher.py` — `publish()` 성공 후 Hugo build 파일 읽어서 검증

### 3.2 Telegram 리포트 확장

기존 `_tg_error()`를 확장하여 검증 결과 포함:

```python
def _tg_validation(blog_id: str, title: str, url: str, validation: dict):
    if validation["passed"]:
        return  # 문제 없으면 침묵
    msg = f"[VALIDATION] {blog_id}: {title}\n{url}\n"
    for i in validation["issues"]:
        emoji = "🔴" if i["severity"] == "ERROR" else "🟡"
        msg += f"{emoji} {i['check']}: {i['msg']}\n"
    send_error(blog_id, "validation", msg)
```

**파일:** `shared/telegram_notifier.py`
