### 2.4 DOTALL regex 패턴 확장

**파일:** `shared/publishers/hugo_writer.py` (`_clean_body`)

**현재:**
```python
body_md = re.sub(r"\n+##\s*(함께|관련|추천)\s*(읽어보기|읽을거리|글|포스트).*", "", body_md, flags=re.DOTALL)
```

**확장:**
```python
body_md = re.sub(r"\n+##\s*(함께|관련|추천|더)\s*(읽어보기|읽을거리|글|포스트|게시물|기사).*", "", body_md, flags=re.DOTALL)
```
