# Plan 02-01: Dispatcher Registry

**Phase:** 2 — Core Refactoring: Simplify Central Modules
**Goal:** Replace elif chain with dynamic pipeline lookup
**Mode:** mvp

## Objective

Replace the brittle 35+ elif chain in `dispatcher.py:_run_pipeline()` with a dynamic registry that imports pipeline modules by convention. New blogs require config change only — no code change.

## Requirements

- STB-07: dispatcher routing refactored
