# Plan 03-02: Error Handling Audit

**Phase:** 3 — Hardening: Stability & Decoupling
**Goal:** Audit and standardize error handling in central modules
**Mode:** mvp

## Objective

Audit all `except` blocks in `dispatcher.py`, `scheduler.py`, and `shared/publisher.py`. Standardize error logging with module prefix + context + error. Eliminate silent bare excepts.

## Requirements

- STB-09: Consistent error handling with actionable messages

## Tasks

### 2.1 Audit dispatcher.py
- Find all `except` blocks
- Replace `except:` / `except Exception:` with specific types where possible
- Standardize format: `logger.error(f"[dispatcher] {context}: {e}")`
- Keep intentionally silent excepts for quota checks

### 2.2 Audit scheduler.py
- Same treatment — standardized logging, specific exception types
- Health check errors should clearly say which check failed

### 2.3 Audit shared/publisher.py
- All `except` blocks in `publish()`, `_write_hugo_post()`, etc.
- Replace bare excepts with `except Exception as e: logger.error(...)`

### 2.4 Verify
- No bare `except:` (without logging) in audited files
- All tests pass, ruff clean, mypy clean

## Verification

- [ ] dispatcher.py: all `except` blocks have context + module prefix
- [ ] scheduler.py: same standard
- [ ] publisher.py: same standard
- [ ] Zero bare `except:` without logging in audited files
