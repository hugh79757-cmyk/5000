**Phase:** 4 — TAP Publishing Stabilization
**Goal:** Trip.com CTA HTML 보존 + 썸네일 이미지 복원
**Mode:** fix

## Objective

리팩토링 과정에서 손상된 2가지 포맷팅 문제를 수정한다:
1. `_clean_body()`가 모든 HTML 태그를 제거하여 Trip.com CTA가 사라짐
2. `_build_frontmatter_blowfish()`의 썸네일 키가 `featureimage:` → `cover.image:`로 변경되어 썸네일 미표시

## Tasks

### 1.1 `_clean_body()`에서 HTML 태그 제거 regex 제거

**파일:** `shared/publishers/hugo_writer.py`
**라인:** 92-98

**수정 전:**
```python
def _clean_body(body_md):
    if not body_md:
        return body_md
    body_md = re.sub(r"</?[^>]+>", "", body_md)  # ← 제거 대상
    body_md = re.sub(r"\n{3,}", "\n\n", body_md)
    return body_md.strip()
```

**수정 후:**
```python
def _clean_body(body_md):
    if not body_md:
        return body_md
    body_md = re.sub(r"\n{3,}", "\n\n", body_md)
    return body_md.strip()
```

**영향도:** `_clean_body()`를 호출하는 모든 경로(publish, hugo_writer flow)에 영향.
CTA HTML이 보존되며, 다른 HTML 요소(iframe, img 등)도 함께 보존됨.

**위험:** 기존에 `_clean_body()`로 HTML을 걸러내던 다른 파이프라인이 있을 수 있음.
- 검증: `pipelines/` 아래에서 `_clean_body` 호출을 검색하여 영향도 확인

### 1.2 `_build_frontmatter_blowfish()` 썸네일 키 복원

**파일:** `shared/publishers/hugo_writer.py`
**라인:** 67-89

**수정 전:**
```python
if thumbnail_url:
    fm += "cover:\n"
    fm += '  image: "' + thumbnail_url + '"\n'
elif "stock" in blog_id:
    fm += 'cover:\n  image: "https://pub-.../stock-default-thumbnail.webp"\n'
else:
    fm += 'cover:\n  image: "https://pub-.../default-thumbnail.webp"\n'
```

**수정 후:**
```python
if thumbnail_url:
    fm += 'featureimage: "' + thumbnail_url + '"\n'
elif "stock" in blog_id:
    fm += 'featureimage: "https://pub-.../stock-default-thumbnail.webp"\n'
else:
    fm += 'featureimage: "https://pub-.../default-thumbnail.webp"\n'
```

**참고:** `sanitize_featureimage_url()` 호출은 이전 버전에도 없었으므로(`d722aab0b` 이전에는 Blowfish frontmatter 빌드 직전에 호출했었음), 복원 시에도 추가하지 않음.

**위험:** stock-hugo 블로그에서 Blowfish 테마가 이미 `cover.image:`를 사용 중이면 회귀.
   → `git log --oneline -1 -- 'shared/publishers/hugo_writer.py'` 확인 불가.
   → **대안:** blog_id에 따라 조건부 처리:
     - `"stock" in blog_id` → `cover.image:` 유지
     - TAP travel blogs (`"travel" in blog_id`) → `featureimage:` 사용
