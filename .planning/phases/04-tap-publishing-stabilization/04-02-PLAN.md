### 2.3 `no_result` backoff 메커니즘 추가

**파일:** `dispatcher.py`
**라인:** 500-550 (no_result 처리 영역)

**방법:** blog_id별 마지막 실패 시간을 기록하고 cooldown 적용

```python
# dispatcher.py 상단 또는 별도 모듈
import json, os
from datetime import datetime, timedelta

_BACKOFF_FILE = os.path.join(os.path.dirname(__file__), "data", "cooldown.json")
_COOLDOWN_MINUTES = 30  # 실패 후 30분간 재시도 방지

def _get_cooldowns():
    try:
        with open(_BACKOFF_FILE) as f:
            return json.load(f)
    except (FileNotFoundError, json.JSONDecodeError):
        return {}

def _set_cooldown(blog_id):
    cooldowns = _get_cooldowns()
    cooldowns[blog_id] = datetime.now().isoformat()
    os.makedirs(os.path.dirname(_BACKOFF_FILE), exist_ok=True)
    with open(_BACKOFF_FILE, "w") as f:
        json.dump(cooldowns, f)

def _is_on_cooldown(blog_id):
    cooldowns = _get_cooldowns()
    last = cooldowns.get(blog_id)
    if not last:
        return False
    elapsed = datetime.now() - datetime.fromisoformat(last)
    return elapsed < timedelta(minutes=_COOLDOWN_MINUTES)
```

**사용 (기존 no_result 로직에 추가):**
```python
if result is None:
    if _is_on_cooldown(blog_id):
        logger.info(f"[SKIP] {blog_id} on cooldown ({_COOLDOWN_MINUTES}min)")
        continue  # or return early
    _set_cooldown(blog_id)
    status = "no_result"
```
