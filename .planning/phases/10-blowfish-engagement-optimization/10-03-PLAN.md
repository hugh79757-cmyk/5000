### Shortcode Details

**gallery:**
```
{{< gallery >}}
  {{< figure src="https://example.com/img1.jpg" alt="View 1" caption="Mountain view" >}}
  {{< figure src="https://example.com/img2.jpg" alt="View 2" caption="Lake view" >}}
{{< /gallery >}}
```
Renders as a grid of images with lightbox support in Blowfish.

**accordion (Blowfish):**
```
{{< accordion >}}
  {{< accordion-item header="전기 시설" >}}
  전기 사용이 가능한 사이트가 20면 있습니다.
  {{< /accordion-item >}}
  {{< accordion-item header="온수 시설" >}}
  온수 샤워실이 4개 있으며, 무료로 이용 가능합니다.
  {{< /accordion-item >}}
{{< /accordion >}}
```
Renders as expandable/collapsible sections.

### Image Data Reality

From the data audit in CONTEXT.md: GoCamping API provides a single `firstImageUrl` per campsite. The `_inject_images()` function in `pipelines/travel/writer.py` (line 421) injects one `![name](url)` per H2 heading.

**Since camping items have single images, gallery shortcode grouping will rarely activate for camping content.** However, the post-processor must still handle the edge case where multiple images appear consecutively (e.g., if an AI hallucination or future enrichment adds extra images). The function should be a no-op when there's only one or zero images.

### Accordion Data Reality

Accordion should target the `## {theme} 선택 시 체크포인트` or `## 방문 전 준비사항` sections where facility info (sbrsCl), pet policy, and checklists appear as bullet lists. The post-processor converts bullet lists under these H2 headings into accordion items.
