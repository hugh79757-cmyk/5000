## 11 Meta-Response Regex Patterns (Foundation Layer)

1. `r"죄송합니다?\s*\."` — apology
2. `r"이미\s+(작성|전달|보내|드렸)"` — already written/sent
3. `r"동일한\s+요청"` — duplicate request
4. `r"앞서\s+(전달|작성|말씀)"` — previously mentioned
5. `r"다음과\s+같은\s+구조"` — structure outline
6. `r"구조로\s+작성"` — written in structure
7. `r"언어\s+모델"` — language model
8. `r"AI\s+(언어\s+모델|모델)"` — AI model
9. `r"As\s+an\s+AI"` — English variant
10. `r"수정.*필요.*있으신가요"` — offering revision
11. `r"다시\s+작성해\s+드리"` — offering rewrite
