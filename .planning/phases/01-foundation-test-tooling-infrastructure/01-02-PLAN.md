# Plan 01-02: Unit Tests for Shared Modules

**Phase:** 1 — Foundation: Test & Tooling
**Goal:** Write unit tests for validators.py, humanizer.py, telegram_notifier.py
**Mode:** mvp
**Depends on:** Plan 01-01 (tooling infra must exist)

## Objective

Achieve >=70% per-module coverage on the first three shared modules: validators, humanizer, and telegram_notifier. These are the most independent and testable modules with pure logic.

## Requirements

- STB-01: Unit tests for validators, humanizer, telegram_notifier

## Tasks

### 2.1 Read source modules and identify test surfaces
- `shared/validators.py` — input validation, sanitization functions
- `shared/humanizer.py` — text processing, language rules
- `shared/telegram_notifier.py` — API messaging, formatting

### 2.2 Write `tests/shared/test_validators.py`
- Test `sanitize_title()` — edge cases, special chars, length
- Test `assert_korean_or_reject()` — Korean vs non-Korean content
- Test any other exported functions
- Mock external dependencies (if any)

### 2.3 Write `tests/shared/test_humanizer.py`
- Test AI-ism replacement patterns
- Test those patterns are NOT present in output
- Test edge cases (empty string, no matches, all matches)
- No API calls — pure text processing

### 2.4 Write `tests/shared/test_telegram_notifier.py`
- Test message formatting (HTML parse mode, markdown)
- Test error handling (missing credentials, API failure)
- Mock `requests.post` for API call tests
- Test `send()` return behavior

### 2.5 Verify coverage
- Run `pytest --cov=shared tests/`
- Check per-module coverage >=70%
- If below threshold, add more tests

## Verification

- [ ] `pytest --cov=shared tests/` shows >=70% coverage on each tested module
- [ ] All tests pass
- [ ] CI passes with both plans complete
