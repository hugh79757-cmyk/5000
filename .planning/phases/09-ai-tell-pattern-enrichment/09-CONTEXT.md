# Phase 9: AI-Tell Pattern Enrichment — humanizer.py

## 배경

`shared/humanizer.py`의 `_SYSTEM_PROMPT`가 im-not-ai `ai-tell-taxonomy.md` v2.0 기준으로
A/C/D/F/G계열만 커버하고 B/E/H/I/J계열이 누락된 상태.

CT 분석에서 누락된 고심각도(S1/S2) 패턴이 다수 확인됨:
- B계열 (영어 인용·용어 과다) — 완전 누락
- E계열 (리듬·종결어미) — 완전 누락
- H계열 (접속사 남발) — 완전 누락
- I계열 (형식명사·의존명사) — 완전 누락
- J계열 (시각 장식) — 완전 누락
- A계열 (번역투) — 고심각도 4패턴(A-15/16/18/19) 누락
