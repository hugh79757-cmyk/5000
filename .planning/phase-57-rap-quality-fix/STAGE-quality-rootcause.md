## Q-C: 수치 모순 125건 (실제 289건 상세 확인)

### 근본원인: **LLM 본문 생성과 표 데이터 주입의 구조적 분리** (구조적 결함)

**대표 사례 3건:**
| 글 | 모순 유형 | 본문 값 | 표 값 |
|-----|-----------|---------|-------|
| rap-hugo/왕십리풍림아이원 | 평균값 모순 | 본문평균=151,600 | 표범위=242,000-355,000 |
| rap-hugo/강동구-천호태영아파트 | 평균값 모순 | 본문평균=105,880 | 표범위=111,000-230,000 |
| rap-hugo/성동구-센트라스 | 최고가 모순 | 본문최고=355,000 | 표최고=247,000 |

**원인:** 
- **표 데이터**: `_build_trade_reference` / `_build_subscription_reference`에서 구조화 데이터로 주입 → 마크다운 표로 렌더링
- **본문 텍스트**: LLM이 독립적으로 생성 (참고자료 참고하되 독립 계산/서술)
- **구조적 분리**: LLM이 표 데이터를 참조해 본문 수치를 계산/작성하지 않고 독립적으로 서술 → 환각/오계산 발생

**해결 방향:** 
1. **본문 수치를 표에서 계산·주입**하는 방식으로 변경 (LLM이 아닌 파이프라인에서 계산)
2. 또는 **검증 게이트 추가**: 본문 수치 vs 표 값 대조 후 불일치 시 재생성/드래프트 강등

**1곳 수정 가능 여부:** 부분 가능
- `_post_process` 단계에서 본문 수치 vs 표 값 교차검증 로직 추가 (1곳)
- 단, LLM 생성 단계 자체를 바꾸려면 프롬프트/파이프라인 구조 변경 필요 (복수 파일)

## Q-D: 중복/유사 2,057쌍 (Jaccard ≥0.7)

### 근본원인: **정상 월별 갱신 + 템플릿 제목 생성의 구조적 중복**

**분류:**
| 구분 | 쌍 수 | 성격 |
|------|-------|------|
| **정상 월별 갱신** (동일 지역·시점, 다른 단지) | ~1,500쌍 | 영등포_2026-05월 58건, 마포_2026-05월 54건 등 — 정상 월별 갱신 |
| **템플릿 유사** (같은 브랜드/단지 패턴) | ~400쌍 | 같은 브랜드/지역에서 제목 템플릿 유사 |
| **무의미 중복** (동일 단지 재발행, 키워드 풀 중복) | ~150쌍 | P1/P2 재발행 문제와 연관 |

**구조적 원인:**
1. **_pick_keyword**: 지역/시점 기반 키워드 선택 → 같은 지역·시점에서 여러 단지 선택 → 정상 월별 갱신 (문제 아님)
2. **프롬프트 템플릿**: 제목 규칙이 "키워드 반영"만 있고 차별화 규칙 없음 → 유사 제목 생성
3. **키워드 풀 중복**: 같은 단지가 다른 시점에 재선택 (P1/P2 문제와 연관)

**진짜 "무의미 중복" 재산정:**
- 정상 월별 갱신 제외 시: **~550쌍** (전체의 ~27%)
- 이 중 키워드 풀 재선택(P1/P2) 관련: ~150쌍
- 템플릿 유사 제목: ~400쌍

**해결 방향:**
1. **제목 다양화 규칙** 프롬프트 추가 (지역/단지 차별화 강제)
2. **_pick_keyword**에 "같은 지역·시점에서 이미 다룬 단지 제외" 로직 추가
3. 제목 생성 후 **유사도 검증 게이트** 추가 (Jaccard ≥0.7 시 재생성/드래프트)
