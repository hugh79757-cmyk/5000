# Design: 키워드 수익 분석 대시보드 + 발행 전략 엔진

- 날짜: 2026-08-20
- 분류: architectural (다중 서브시스템 — 분석 대시보드 + 발행 전략 엔진으로 분해)
- 목적지: 수익 (AdSense + 제휴 복합)
- 현재 위치 (성숙도 지도): L1 (감시)
- 목표: L4 (수익 최적화)

## 배경 요약

- 최종 목표: "사용되는 키워드가 어떤건지, 키워드에 따른 피치 단가가 어땠는지, 그에 따른 수익은 얼마였는지 세세하게 분석할 수 있는 도구" → 이를 기반으로 성과 목표 기준의 신규 발행 전략.
- 결과물 우선순위: **분석 대시보드 먼저** (발행 전략 엔진은 그 다음).
- 피치 단가 정의: **실적 기반 추정 단가** (EPC).
- 성숙도 레벨 지도: L0 수동 → L1 감시 → L2 진단+수정지시 → L3 자동 복구 → L4 수익 최적화 → L5 자율 운영. 현재 = L1.

## 섹션 1: 데이터 연결 골격 [승인됨]

### 1-1. 데이터 소스 현황 (검증됨)

| 소스 | DB/테이블 | 단위 | 상태 |
|------|-----------|------|------|
| AdSense | `data/analytics.db` `adsense_daily` | domain | 2393행 / 110도메인 / 2026-03-19~07-28 (4.3개월, 충분) |
| GSC 키워드 | `gsc_keywords` | **blog_id** (UNIQUE(blog_id,date,query)) | 373행 / 218키워드 / 14일 (얇음) |
| GSC 페이지 | `gsc_pages` | blog_id + page(URL) | **0행** |
| GA4 페이지 | `ga4_pages` | blog_id + page_path | 존재 |

- `gsc_keywords`, `gsc_pages`, `ga4_pages`는 이미 blog_id 단위 → 조인 가능.
- `adsense_daily.domain` → blog_id 매핑만 Phase 1에서 필요.

### 1-2. 도메인→blog_id 매핑 (Phase 1)

- `adsense_daily.domain`을 blog_id로 연결하는 매핑 테이블/로직 필요.
- 주의: `foodwater.tistory.com` (티스토리) 등 5000 인벤토리 밖 도메인 존재 → 매핑에서 제외/분리 표시.

### 1-3. 키워드 EPC 계산법 (확정)

```
키워드 추정 수익 = (키워드 GSC 클릭 ÷ 블로그 전체 GSC 클릭) × 블로그 일일 AdSense 수익
키워드 EPC = 키워드 추정 수익 ÷ 키워드 클릭
```

- 해석: 블로그 일일 AdSense 수익을 "클릭 기여 비율"로 키워드에 배분.
- 한계: 키워드 클릭 ↔ AdSense 노출/클릭의 정확한 1:1 대응 아님 — 추정치. 대시보드에 "추정 수익" 라벨 필수.

## 섹션 2: 키워드 EPC 계산 + 분석 지표 정의 [초안 — 승인 대기]

### 2-1. 키워드 추정 수익 공식

섹션 1-3과 동일 공식 사용. 클릭 기반 배분 (PV 기반보다 AdSense 수익과 상관 높음).

### 2-2. 분석 지표 정의 (3개 레벨)

- **L1 블로그/도메인**: 수익(일/주/월), PV, 클릭, RPM, CTR, 7일·30일 추세선(증감율).
- **L2 키워드**: 노출, 클릭, CTR, 평균 순위(포지션), 추정 수익, **EPC**. 정렬 토글(수익/EPC/클릭), 필터(기간·블로그·최소 클릭).
- **L3 게시글**: page_path, PV(ga4_pages), 소속 키워드 (gsc_pages 0행 → 초기엔 ga4_pages PV만, 키워드 연결은 Phase 2+).

### 2-3. 데이터 표시 규칙

- "추정 수익" 라벨 강제.
- 노이즈 필터: 클릭 < 3인 키워드 기본 숨김.
- 기간 기본값: 최근 28일 (GSC 롤링 기준).

### 2-4. 키워드 랭킹 테이블 (예시)

| 키워드 | 클릭 | CTR | 평균순위 | 추정수익 | EPC | 블로그 |
|--------|------|-----|---------|---------|-----|-------|
| gr86 유지비 | 45 | 4.2% | 3.1 | $3.87 | $0.086 | car.rotcha.kr |
| 스타일런 2026 | 32 | 5.8% | 2.4 | $2.95 | $0.092 | ... |

→ 이 테이블이 곧 발행 전략 엔진의 입력값 (다음 섹션에서 설계).
