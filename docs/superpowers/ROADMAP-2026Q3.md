# ROADMAP 2026 Q3 — ETAP 품질 전면 개편

> **관통 원칙: 생산 경로를 먼저 고치고 계측기는 마지막에 손댄다.**

## 단계

### 1. airports 색인차단 지혈
- 목적: 자료 부족 공항 포스트가 검색엔진에 수집되지 않도록 noindex로 즉시 차단한다.
- 완료 판정: 배포 후 STN·PEK·KDL 라이브 HTML에서 `<meta name="robots" content="noindex">` 원문 확인.
- 선행 조건: 이미지 게이트의 robots 전용 FM 변경 예외(P0)와 extend_head 메타 렌더 준비.

### 2. 36블로그 수익화 생존 실측
- 목적: 광고·어필리에이트가 실제로 살아있는 블로그 수를 라이브 렌더에서 측정해 수익화 생존율을 확정한다.
- 완료 판정: 36블로그 각 1포스트 이상 per-post 실측 표(광고 유무·rel=sponsored 수·GA4 ID) 완성.
- 선행 조건: 1단계 종료(배포 채널 정상 복구).

### 3. 어필리에이트 사망 원인 커밋 특정
- 목적: bath·ensenada 외 어필리에이트가 전부 0이 된 시점과 그 커밋을 특정한다.
- 완료 판정: rel=sponsored 0 전환 경계 날짜와 해당 writer/템플릿 커밋 해시 지목(diff 발췌 포함).
- 선행 조건: 2단계의 per-post 실측 데이터.

### 4. 생산 경로 복구
- 목적: PoC writer 차단, 이미지·front-matter·twitter:card 누락 없는 정상 발행 경로를 복구한다.
- 완료 판정: 신규 발행 1건이 R13(본문 이미지)·R16(og:image)·R17(twitter:card) 충족 채로 라이브 확인.
- 선행 조건: 3단계에서 사망 원인 규명.

### 5. 승인 없으면 배포 차단하는 잠금 구현
- 목적: 사람의 승인 없이는 배포 자체가 진행되지 않는 잠금을 배포 경로에 넣는다.
- 완료 판정: 승인 마커 부재 상태에서 deploy 호출이 차단되고, 승인 마커 존재 시에만 통과하는 테스트 통과.
- 선행 조건: 4단계에서 생산 경로가 정상화되어 있을 것.

### 6. 미쉐린 라이브 하한 13패밀리 통일
- 목적: 미쉐린 라이브 하한(wordCount≥706 등)을 13패밀리 전체 기준선으로 통일하고, 자료가 분량을 못 채우는 패밀리는 발행을 중단한다.
- 완료 판정: 패밀리별 기준선 문서 13건 확정 및 자료 부족 패밀리의 스케줄 비활성화 확인.
- 선행 조건: 패밀리별 자료 충분성 판정 자료.

### 7. 계측기 정리
- 목적: 공허 통과 제거, 삼상태(통과/미달/해당없음) 집계, 대시보드 재실험으로 계측기를 마지막에 정리한다.
- 완료 판정: 모든 탐지 규칙이 부재값을 "해당없음"으로 집계하고 대시보드 재실험이 통과.
- 선행 조건: 1~6단계 전부 완료.

## 상시 트랙 — 모델 tier 위생
- 목적: 글쓰기 폴백 체인에서 어떤 tier(모델)가 무엇을 썼는지 로그가 남고, CJK 누출 등 저품질 산출이 tier로 역추적 가능하게 유지한다.
- 완료 판정: 발행 로그에 tier 기록 상시 존재 + 보존 정책 문서화.
- 선행 조건: 없음(전 단계와 병행).
