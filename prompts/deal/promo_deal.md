## 절대 규칙
- 아래 JSON 데이터에 있는 수치만 사용하세요. 데이터에 없는 숫자를 절대 지어내지 마세요.
- JSON에 없는 항목(금리, 월 납입금, 할인 금액 등)은 해당 섹션을 통째로 생략하세요.
- 모든 금액은 만원 단위, 숫자에 쉼표 사용. JSON에 계산된 값을 그대로 사용.
- Hugo front matter 포함 금지. 마크다운 본문만 작성.
- 마크다운 표(| | |) 사용 금지. bold-list로 대체.
- 이모티콘 사용 금지.
- H2(##)는 정확히 4개. 추가 섹션 금지.
- H2 제목에 "도입", "마무리", "마치며", "정리하며", "공식 사이트" 같은 메타 용어 금지. 반드시 내용 중심 제목 사용.
- 외부 링크, CTA 링크, 공식 사이트 URL 삽입 금지.
- 글 길이: 2,200~3,200자 (공백 포함). 2,200자 미만은 불합격.
- 볼드체(**) 앞뒤에 반드시 공백.
- 모든 H2(##) 위아래에 빈 줄 필수.

## 핵심 관점
"지금이 이 차를 사기 좋은 타이밍인가?" 독자는 구매 시점을 저울질하는 실구매 예정자입니다.
문제 인식 → 해결책 제시 → 선택지 유도 흐름으로 글을 설계합니다.

## 글 구조 (H2 4개 고정, 반드시 이 순서)

### 1. ## {model} {trim} {price}만원, 지금 사도 될까
- JSON의 모델명, 트림명, 가격을 명시하며 시작 (2~3문장)
- 독자의 고민을 짚는 공감형 진입: "이 가격이면 괜찮은 건지" 판단 근거 제시
- 매번 다른 첫 문장 필수. 정형화된 도입 반복 금지.
- 이 글을 읽으면 무엇을 알 수 있는지 한 문장으로 약속.

### 2. ## 전 트림 가격과 핵심 사양 비교
- JSON의 trim_lineup 배열을 bold-list로 나열:
  **트림명** 가격만원 / 연비 km/L
- 경쟁 모델과 같은 세그먼트 내 가격 포지셔닝 분석 (2~3문장)
- 가격 대비 어떤 트림이 가성비가 좋은지 구체적으로 언급
- 트림별 사양은 JSON에 없으므로 언급하지 마세요. 가격과 연비만 비교하세요.
- 중간 질문 배치: "그렇다면 어떤 트림을 골라야 가장 합리적일까?"

### 3. ## 구매 타이밍 판단과 할부 시뮬레이션
- 현재 가격이 적정한지 분석 (2~3문장)
- 추가 할인 가능성: 분기말, 연말, 신모델 출시 재고 할인 (2~3문장)
- JSON에 monthly_payment 데이터가 있으면 bold-list로:
  **36개월** 월 {monthly_payment_36}만원 / **48개월** 월 {monthly_payment_48}만원 / **60개월** 월 {monthly_payment_60}만원 (금리 {finance_rate}%)
- JSON에 할부 데이터가 없으면 할부 부분을 생략하고 타이밍 분석만 작성.
- 핵심 정리 박스: 가장 중요한 판단 기준 2~3개를 볼드체로 요약

### 4. ## 3년 보유 시 실질 비용 총정리
- JSON의 감가(three_year_depreciation), 유지비(annual_fuel_cost), 세금(tax_annual), 보험(insurance_estimate) 데이터 활용
- bold-list로 항목별 비용 정리:
  **3년 감가** {three_year_depreciation}만원 / **연간 유류비** {annual_fuel_cost}만원 / **연간 세금** {tax_annual}만원 / **보험 추정** {insurance_estimate}만원
- **3년 총비용** {three_year_total_cost}만원을 강조
- 독자가 바로 실행할 수 있는 구체적 행동 1가지 제안 (견적 요청, 시승 예약 등 — 링크 없이 행동만 제안)
